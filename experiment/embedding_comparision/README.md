コードの解説と実験のポイント
グラフ生成:
nx.barabasi_albert_graph を使用して、現実のネットワーク（SNSなど）でよく見られる「ハブ」を持つグラフを生成します。これにより、PageRankの値に明確な差が生まれます。

PageRankと配色:
グラフの構造的な中心性を示すPageRankを計算し、値が低いノードを青色、高いノードを赤色とするグラデーションで色付けします。この配色は3つの可視化すべてで共通して使用します。

Node2Vec (ユークリッド埋め込み):

Node2Vecは、グラフ上のノードをユークリッド空間（我々がよく知るまっすぐな空間）のベクトルとして表現します。
学習されたベクトルは高次元なため、t-SNEという手法で2次元に圧縮して可視化します。
見るべきポイント: PageRankが高い赤いノード群が、空間内で近くに集まっているか。また、青い末端ノード群と分離されているか。
Poincaré Embedding (双曲埋め込み):

gensimのPoincareModelを使い、ノードを双曲空間（歪んだ空間）のベクトルとして表現します。ここではポアンカレ円盤モデルで可視化します。
見るべきポイント: 双曲空間では、中心（原点）が最も重要で広大なエリアとなります。PageRankが高い赤いノードが、円盤の中心付近に集まり、PageRankが低い青いノードが円盤の**縁（無限遠）**の方へ追いやられているかを確認します。この傾向が強ければ、双曲空間がグラフの階層性や中心性をうまく捉えられていると言えます。
この実験を通じて、同じグラフデータでも、埋め込む空間の幾何学的性質によって、ノード間の関係性の表現のされ方が大きく異なることを視覚的に確認できます。
